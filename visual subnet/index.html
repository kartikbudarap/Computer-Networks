01IP Address & Subnet Mask
+

An IPv4 address is a 32-bit identifier written in dotted-decimal notation, e.g. 192.168.1.1. Each of the four octets represents 8 bits (0–255).

A subnet mask separates the network portion (leading 1-bits) from the host portion (trailing 0-bits). Devices sharing the same network bits can communicate directly without a router.

Example IP
192.168.1.10
Subnet Mask
255.255.255.0
CIDR
/24

CIDR /24 means 24 leading 1-bits — equivalent to 255.255.255.0.

02Key Formulas
+

All subnet values derive from these bitwise operations (given IP and prefix n):

Mask = (0xFFFFFFFF << (32-n)) & 0xFFFFFFFF Network Address = IP & Mask Broadcast = Network | (~Mask) First Usable = Network + 1 Last Usable = Broadcast - 1 Total IPs = 2^(32 - n) Usable Hosts = 2^(32 - n) - 2

Two addresses are reserved: the network address (all host bits = 0) and the broadcast address (all host bits = 1). Exception: /31 allows 2 usable hosts on point-to-point links (RFC 3021).

03IP Classes & CIDR
+
Class A
1–126 · /8
Class B
128–191 · /16
Class C
192–223 · /24

CIDR (RFC 1519, 1993) replaced fixed classes with arbitrary prefix lengths, enabling efficient allocation. VLSM extends CIDR within an organization — different subnets can use different prefix lengths.

04Wildcard Mask & ACLs
+

A wildcard mask is the bitwise complement of the subnet mask. 0-bits mean "must match"; 1-bits mean "don't care".

Wildcard = ~Subnet Mask Example: /24 mask = 255.255.255.0 → Wildcard = 0.0.0.255

Wildcard masks appear in Cisco IOS ACLs and OSPF area definitions. E.g., permit 192.168.1.0 0.0.0.255 permits all addresses in 192.168.1.0/24.

05Private Ranges (RFC 1918)
+
Class A Private
10.0.0.0/8
Class B Private
172.16.0.0/12
Class C Private
192.168.0.0/16

These ranges are non-routable on the public internet and require NAT to reach external hosts. Loopback 127.0.0.0/8 is reserved for host self-communication.
